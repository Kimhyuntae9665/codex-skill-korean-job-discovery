# Examples (workflow examples, not verified vacancies)

- “부산·경남 신입 QA/기술지원·로봇 검증, 정규직·인턴만 찾아줘.”
  Use it+rnd, applicable region/universities and aliases. Exclude unrelated overseas/bio.
  연구원 does not automatically imply bachelor's eligibility.
- “서울 금융데이터·운용지원 인턴을 비교해줘.”
  KOFIA member hiring + junior/foreign sources as applicable → official employers.
  KOFIA's own staffing ATS is not the member-company industry board.
- “A회사의 신입 IT 채용만 알아봐.”
  Company mode; employer careers/ATS and selected employer-name searches.
  No unrelated TIPS company discovery.
- “원티드·사람인 말고 연구지원 채용을 찾을 경로를 알려줘.”
  Channels mode with source exclusions; route operation/degree bias, not job fit.
- “Read skills/korean-job-discovery/SKILL.md. Research entry-level IT support
  in Seoul. Return run JSON and a Korean coverage report. Use available web tools;
  do not apply, contact employers or create alerts.”
  Load routing/catalog, verification/handoff. Helpers are plans, not completed searches.
